# Acharwala.com - Development

Single vendor eCommerce Website & POS with extensively managing of Order Management System with Delivery Ticket Printing System.

## Features of Acharwala.com
- Responsite Design with Static content (dynamic).
- Header & Footer
- Homepage
- Aboutpage 
- Admin
    1. User Login & Registration. 
    2. Dashboard. 
    3. Site Info Settings. 
    4. Notice & Press Release. 
    5. Page - (Add, Edit, Delete, View & List) with multiple page template. 
    6. Social Settings. 
    7. Message/Contact form. 
    8. Menu & Dropdown Menu. 
    9. User Management System with Designation & scopes. 
    10. Profile - 
    11. Change Password. 
    12. Logout. 

## Technology
    1. Laravel8 - API.
    2. Jwt Authentication - Security System.
    3. Sneat - Admin Template
    4. Vue Js - Admin Panel Development. 
    5. Custom and premium version - Web Template using Bootstrap, jQuery and Custom CSS + JavaScript.
    6. ReactJs - Frontend
